# SnapLite App Manager

A simple Linux software management demo built with Python and Flask.

## Features

- Add applications to the installed applications list
- View installed applications
- Remove applications from the list
- Simple and easy-to-use web interface

## Requirements

- Linux / WSL Ubuntu
- Python 3
- Flask

## Setup

Clone the repository:

```bash
git clone https://github.com/AaronNyamekye/snaplite-app-manager.git
cd snaplite-app-manager
